# Dino Game: Hands Up Beta!

## Introduction
This game is a simple dino run game that use Python third-party library "Pygame" for game development. Besides, this program also implement another Python third-party 
library which is "Mediapipe" for hand gesture function. Once the program is started, the user webcam (if have) will automatically open and start to detect. Users allow
to raise up your hand to control the dinosaur for jumping.
